# Free Search 0.1.0-preview 快速开始

完整说明和限制见 [README](../README.md)，验收记录见 [VALIDATION](VALIDATION.md)。

## 安装

从 [Release](https://github.com/Misaka-11736/Free-Search/releases/tag/v0.1.0-preview)
下载安装 EXE 和同版本全部 BIN 数据分卷，放在同一目录，保留名称，再运行 EXE。
不要解压 BIN，不要只下载 EXE。安装包包含全部本地模型，不需要安装 Python。

一次安装生成两个开始菜单入口：完全离线版、API 版，共用模型和索引。
程序默认在 `%LOCALAPPDATA%\Programs\FreeSearch`，数据默认在
`%LOCALAPPDATA%\FreeSearch\data`。卸载保留数据目录及已保存系统凭据。

## 使用

1. 启动完全离线版，添加一个文档或图片目录。
2. 点击“建立／增量更新索引”，等待内容处理完成。建议从小目录开始。
3. 输入内容描述后搜索，选中查看片段和位置，双击打开原文件。
4. 左侧可设置扩展名、目录和修改时间过滤。
5. “以图搜图”接受图片；“语音文件提问”接受已有录音，不含麦克风录制。
6. 文件变化后手动增量更新；暂停在当前文件完成后生效，再次更新复用已处理文件。

自然语言里的时间和类型不会自动变成过滤条件。移除目录只影响后续扫描，已有索引仍可搜索。

## API 与诊断

API 版默认本地。服务须兼容 POST /rerank；普通聊天接口不能替代。
授权按当前目录、文本、图片衍生文字、音视频衍生文字区分，仅当前会话有效。
只发送查询及有限候选文字，不上传原始媒体。语音问题还校验来源目录与类型授权。
点击“恢复本地”停止 API 重排。真实收费服务尚未验证。

窗口 EXE 没有终端输出，CLI 使用 `--output` 保存 JSON，错误写入数据目录
`command-error.log`。`--data-dir` 可自定义索引位置；两个入口需设置相同路径才能共享。

自行制作的便携目录必须整体保留 EXE、`_internal` 和 `models`，没有安装标记时，
数据沿用 EXE 同级 `runtime-data`。不要把运行数据上传到公开仓库。

CPU 推理、视频十秒抽帧、DWG 等仅元数据、无视觉交叉重排等边界详见 README。
当前未完成干净 Windows 断网环境的完整验收，安装器未签名。
